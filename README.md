«МедПлан» — веб-приложение для записи пациентов на приём к врачу.

Используемые технологии
* Java 25
* Spring Boot
* Spring Data JPA
* Spring Security
* H2 Database
* HTML, CSS, JavaScript
* Maven

Основные возможности
* Регистрация и авторизация пользователей.
* Просмотр списка врачей и специальностей.
* Просмотр расписания врачей.
* Запись на приём к врачу.
* Просмотр своих записей.
* Отмена записи.

Инструкция по запуску
1. Установить Java 25.
2. Скачать проект.
3. Открыть папку проекта в VS Code.
4. Открыть терминал PowerShell.
5. Перейти в корневую папку проекта.
6. Выполнить команду: .\mvnw.cmd spring-boot:run
7. Дождаться запуска Spring Boot.
Открыть браузер и перейти по адресу:  http://localhost:8080
